青山利康 SRM 供应商智能问答助手

面向供应商的检索增强问答（RAG）系统，嵌入 SRM 系统，帮助供应商自助使用系统。
基于《SRM 业务蓝图 V5.0》，答案带蓝图流程码（QS_SRM_*）出处引用。

核心能力

真·大模型问答

DeepSeek 流式生成，未配 Key 自动降级检索直答，演示无忧。

混合检索 + 重排

向量 + BM25 + RRF 融合；LLM 重排提升 Top-N 相关性。

引用溯源

每个答案标注 QS_SRM_* 流程码与来源片段，可点击查看。

鉴权 / RBAC

JWT（供应商/管理员）+ 服务级 API Key，端点级权限控制。

限流 / 可观测

按 IP 限流；结构化日志；Prometheus 指标端点。

运营后台

管理员查看会话/消息/反馈/知识库/检索命中统计。

专业前端

React+Vite+TS：流式、引用卡、反馈、主题、iframe 桥接。

工程外壳

ruff/black/mypy、pytest+Vitest、CI、Docker、MIT。

在线演示

将你部署后的地址填入，即可在此内嵌实时体验（需你的服务可公网访问）：

填入部署地址后点击「加载演示」；或本地运行 npm run dev + 后端 uvicorn 体验。

本地运行

# 后端
cd backend
pip install fastapi uvicorn pydantic-settings httpx sqlalchemy scikit-learn numpy \
  jieba slowapi prometheus-client structlog "python-jose[cryptography]" "passlib[bcrypt]" python-docx
cp ../.env.example ../.env        # 填写 DEEPSEEK_API_KEY
python -m knowledge.build_kb      # 首次构建知识库
uvicorn app.main:app --port 8000

# 前端
cd frontend && npm install && npm run dev   # http://localhost:5173

Docker 一键：docker compose -f deploy/docker-compose.yml up -d --build
